Data from [TempEval3](https://aclanthology.org/S13-2001.pdf) formatted in JSON. TempEval 3 has _silver_ standard and _platinum_ standard datasets. It was used in SemEval 2012 for the following tasks:
1. Temporal expression extraction and normalization.
2. Event extraction and classification.
3. Annotating temporal relations: From raw text extract the temporal entities (events and  timexes), identify the pairs of temporal entities that have  a temporal link (TLINK) and classify the temporal relation between them.
